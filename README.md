# Academic Success Prediction - EDA and Ensemble ML (Kaggle PS S4E6)

Multi-class classification of university student outcomes (**Graduate / Dropout / Enrolled**) comparing seven model families and three ensembling strategies with 5-fold stratified cross-validation.

- Competition: [Kaggle Playground Series S4E6](https://www.kaggle.com/competitions/playground-series-s4e6/)
- Original data: [UCI - Predict Students' Dropout and Academic Success](https://archive.ics.uci.edu/dataset/697/predict+students+dropout+and+academic+success)
- Author: Khaled Saber, M.Sc. AI Engineering, Near East University

## Credit
The notebook is adapted from the public Kaggle notebook *Academic Success: EDA which makes sense*. This repository packages it so it runs locally, documents the results, and serves as my worked study of a strong tabular-ML pipeline (EDA, categorical handling, CV, tuning, stacking).

## Data
76,518 training rows (synthetic, generated by Kaggle from the original data), 36 features, plus the 4,424-row original dataset. Classes are not severely imbalanced.

## What is inside
- Feature distributions and correlations, train/test/original comparison (Mann-Whitney U)
- Decision tree showing the two strongest signals: `Curricular units 2nd sem (approved)` and tuition-fee status
- Shared `cross_validate` function storing out-of-fold and test probabilities
- Models: ExtraTrees, Random Forest, XGBoost, LightGBM, CatBoost, DART, Logistic Regression (with one-hot and splines)
- Ensembles: hard voting, ridge stacking, logistic stacking, with calibration plots

## Results (5-fold CV)
| Model | Accuracy | Log loss |
|---|---|---|
| ExtraTrees 1 | 0.82551 | 0.45155 |
| ExtraTrees 2 | 0.82599 | 0.45916 |
| Random forest 1 | 0.82799 | 0.45226 |
| Random forest 2 | 0.82634 | 0.44820 |
| XGBoost untuned | 0.83150 | 0.43800 |
| XGBoost tuned 1 | 0.83443 | 0.42862 |
| XGBoost tuned 2 | 0.83433 | 0.42685 |
| XGBoost tuned 3 | 0.83507 | 0.42728 |
| LightGBM untuned | 0.83282 | 0.43358 |
| LightGBM tuned | 0.83515 | 0.42822 |
| CatBoost tuned | 0.83285 | 0.43389 |
| DART | 0.83448 | 0.42837 |
| LogisticRegression | 0.82669 | 0.45293 |
| Hard voting | 0.83451 | - |
| Stacking (ridge) | 0.83527 | 0.43639 |
| Stacking (logistic) | 0.83506 | 0.42642 |

**Reading the table**
- Boosting beats bagging and the linear baseline (about 0.833-0.835 vs 0.826-0.828).
- Tuning XGBoost: 0.83150 to 0.83507.
- Best single model is tuned LightGBM (0.83515); ridge stacking is best overall (0.83527), a very small gain (about 0.0001).
- Logistic stacking has the best log loss (0.42642).

## Run it
```bash
pip install -r requirements.txt
# download train.csv and test.csv from the competition page, and the original dataset (rename to original.csv)
# put all three in data/
jupyter notebook pss4e6-eda-ensemble.ipynb
```
A full run takes roughly 1 hour (several 800+ tree models). Set `COMPUTE_TEST_PRED = False` in the configuration cell to skip test predictions.
